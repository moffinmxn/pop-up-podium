# Pop-up Podium
A simple console-based randomization system that allows users to enter two or more options and receive one randomly selected result. It eliminates indecision for task assignments, activity selection, and everyday choices.

--

## Features

- **Flexible Inputs:** Accepts two or more custom options per session.
- **Input Validation:** Prevents empty inputs or fewer than the required minimum options.
- **Unbaised Selection:** Uses standard pseudo-random algorithms to ensure fair outcomes.

--

## Prerequisites
A C++ compiler supporting C++11 or higher

--

# Purpose
This project was built to practice core C++ programming fundamentals, including:

- Standard input/output stream handling (*cin*, *cout*)
- Dynamic collections with *vector* and strings with *string*
- Loop structures and robust input validation
- Random number generation using standard C++ random libraries (*<random>*)
