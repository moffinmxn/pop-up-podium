# Pop-up Podium
A simple randomization system that allows users to enter three or more options and receive one randomly selected result. The project provides a quick and unbiased way to choose between multiple possibilities, making it useful for everyday decisions, activity selection, task assignment, and similar situations.

# Purpose
This project was created to practice fundamental programming concepts, including user input, data storage, loops, input validation, and random selection. It also serves as a foundation for developing more interactive decision-making applications.
